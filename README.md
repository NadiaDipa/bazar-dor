# Bazar Dor (বাজার দর) - Daily Market Price Tracker

Bazar Dor is a modern, responsive web application built to help users check and stay updated with daily essential commodity prices (rice, dal, oil, vegetables, fish, meat, eggs, spices, etc.) in Bangladesh.

## ✨ Features

- **Daily Price Overview:** View up-to-date market prices and price change percentages (increase/decrease) at a glance.
- **Category-wise Filtering:** Easily navigate through different essential categories like Rice, Dal, Oil, Vegetables, Fish, and Meat.
- **User Authentication:** Secure sign-in, sign-up, and session management powered by **Better Auth**.
- **User Profile Management:** View personalized user details and manage profile sessions.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens with a clean UI built using Tailwind CSS and DaisyUI.
- **Bengali Language Support:** Complete interface designed natively in Bengali.

---

## 🛠️ Tech Stack

- **Framework:** Next.js (App Router, React)
- **Styling:** Tailwind CSS, DaisyUI
- **Authentication:** Better Auth (with MongoDB adapter)
- **Language:** TypeScript / JavaScript
- **Deployment:** Vercel
